# TEHIRA Website

Website tĩnh đa trang, responsive, bám theo thiết kế TEHIRA đã chốt.

## Chạy nhanh
- Mở `index.html` trực tiếp, hoặc
- Chạy `python -m http.server 8080` trong thư mục dự án rồi mở `http://localhost:8080`.

## Trang có sẵn
Trang chủ, Dịch vụ, Vấn đề của bạn, Công nghệ, Chuyên gia, Kết quả, Kiến thức, Hệ thống cơ sở, Về TEHIRA, Liên hệ, Đặt lịch.

## Chưa nối backend
Form/đặt lịch hiện chạy demo front-end. Có thể nối CRM/API ở bước tiếp theo.
